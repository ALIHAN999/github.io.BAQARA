# Правила проекта

## Язык

- Отвечай и комментируй код по-русски.
- Сообщения коммитов — по-русски.
- Названия переменных, функций и файлов — по-английски.
- Тексты интерфейса (подписи, кнопки, заголовки) — по-русски.

## Проект

Статическая страница для разбора арабского текста Корана: аят целиком, пословный
разбор, аудио чтецов, навигация по аятам.

- `index.html` — единственный HTML-файл, точка входа.
- `audio/<чтец>/<сура>/<аят>.mp3` — аудио. Чтецы: `husary`, `shaatree`, `ghamadi`,
  `alafasy`. Басмала лежит как `audio/<чтец>/1/1.mp3`.
- `font/UthmanicHafs1Ver18.ttf` — файл основной гарнитуры, подключён через `@font-face`.

## Данные

- Аяты хранятся в массиве `sentences` внутри `index.html`.
- Басмала — элемент с `ayah: 0` и `isBasmala: true`, в списке показывается как
  «Басмала», а не «Аят 0».
- Текст аятов — усманская редакция (api.quran.com, `quran-uthmani`). При добавлении
  новых аятов брать текст оттуда же, чтобы весь корпус был из одного источника.
- Слова в `cells` должны посимвольно содержаться в `sentence` соответствующего аята.

## Арабский текст и шрифты

- Основная гарнитура — `KFGQPC Uthmanic HAFS` (переменная `--arabic-font`),
  берётся локально из `font/`, без обращений к CDN.
- Не использовать `U+06DF` (малый круглый ноль) в тексте и карточках: в браузере он
  рисуется как заметный кружок и выглядит как ошибка. Вместо него — обычный сукун
  `U+0652`. Это осознанное отступление от канонической записи ради читаемости.
- Знаки вақфа (`U+06D6`–`U+06DC`) обрабатываются функцией `renderArabicWithWaqf`.
- При правке арабского текста проверять, что слова карточек совпадают с текстом аята.

## Стиль кода

- Чистый HTML/CSS/JS без сборки и зависимостей.
- Не добавлять фреймворки и npm-пакеты без явной просьбы.
- Стили — в `<style>` того же файла, переменные в `:root`.
- Проверять синтаксис после правок: `node -e "new Function(...)"` для скриптов,
  баланс скобок для CSS.

## Проверки перед завершением

- Синтаксис JS валиден, CSS-скобки сбалансированы.
- Все пути к аудио из `sentences` существуют на диске.
- Слова карточек содержатся в тексте своих аятов.

## Гигиена

- Не оставлять в проекте временные файлы: скрипты проверок, дампы, резервные копии.
- Проверки выполнять инлайн через `node -e`, не создавая файлов.
