# BAQARA — сайт для пословного разбора Корана

Статический сайт без сборки и зависимостей: откройте `index.html` в браузере —
и всё работает. Никаких фреймворков, npm-пакетов и серверов.

## Возможности

- **Меню выбора сур** (`index.html`) — карточки доступных сур с номером,
  названием и арабским написанием.
- **Страница чтения суры** — аят целиком (усманский расм), пословный разбор
  (карточки «слово → перевод»), перевод Кулиева во всплывающем окне.
- **Аудио четырёх чтецов** — аль-Хусари, аш-Шатри, аль-Гамиди, аль-Афаси;
  переключение вкладками в блоке «Послушать аят».
- **Навигация по аятам** — кнопки «Предыдущий аят» / «Следующий аят» внизу
  и модальное окно выбора аята.
- **Выбор суры на ходу** — иконка-меню в шапке страницы чтения открывает
  всплывающее окно со списком сур; текущая подсвечена.
- **Режим изучения** — текст аята скрыт до нажатия кнопки «Показать аят
  целиком», чтобы сначала попробовать разобрать слова самому.
- **Полноэкранный режим** — кнопка разворачивания в шапке.
- Адаптивная вёрстка: страница чтения занимает всё окно, список слов —
  во фрейме со скроллом, аудио и навигация прижаты к низу экрана.

## Структура проекта

```
index.html   — меню выбора сур (главная страница)
fatiha.html  — сура 1 «аль-Фатиха» (аяты 1–7; басмала — первый аят)
baqara.html  — сура 2 «аль-Бакара» (басмала + аяты 1–25; корпус пополняется)
audio/<чтец>/<сура>/<аят>.mp3 — аудиофайлы
font/UthmanicHafs1Ver18.ttf — основная арабская гарнитура
AGENTS.md    — правила проекта (источники текста и перевода, проверки)
```

Чтецы: `husary`, `shaatree`, `ghamadi`, `alafasy`.

## Запуск

Скачайте репозиторий и откройте `index.html` двойным кликом — или подайте
папку любым статическим сервером, например:

```sh
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Источники данных

- **Арабский текст** — усманская редакция (расм ‘усмани, чтение Хафса),
  API [api.quran.com](https://api.quran.com) (`quran-uthmani`).
- **Перевод** — Кулиев, дословно с
  [quran.nurtech.dev](https://quran.nurtech.dev/).
- **Аудио** — [everyayah.com](https://everyayah.com/) (131 кбит/с / 40 кбит/с).
- **Шрифт** — KFGQPC HAFS Uthmanic Script v0.18, Комплекс печати Короля Фахда
  ([qurancdn.com](https://qurancdn.com)), локально в `font/`.

Тексты и аудио распространяются их правообладателями в образовательных целях;
проект не претендует на авторство перевода Кулиева и записей чтецов.

## Особенности арабской графики

- Малый круглый ноль `U+06DF` (малый сукун в канонической записи) заменён
  обычным сукуном `U+0652` — в браузере он читается чище.
- Знаки вақфа (`U+06D6`–`U+06DC`) обрабатываются скриптом
  `renderArabicWithWaqf` и выводятся отдельно от текста.
- Слова в карточках разбора посимвольно содержатся в тексте аята
  (проверяется перед публикацией).
